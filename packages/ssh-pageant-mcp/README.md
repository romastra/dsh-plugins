# SSH через Pageant

Локальная конфигурация DSH для [Nightreaver/python-ssh-mcp](https://github.com/Nightreaver/python-ssh-mcp/tree/73c00c9b0d26add59798bc7b39dff88ac547b15a) (GPL-3.0). Его исходник не продублирован. Пакет запускает MCP под Windows с уже работающим Pageant, проверяет ровно один настроенный публичный отпечаток ключа и сохраняет обязательную проверку ключей серверов.

1. Установите bundle из Discover: запись выключена и ничего не подключает.
2. Из клона репозитория создайте отдельный Windows x64 CPython 3.11 venv и установите в него `requirements.lock` (нужны Git и pip). Не копируйте venv в репозиторий.
3. В приватной конфигурации профиля задайте значения из [примера](profile.example.yml). `config.env.SSH_HOSTS_FILE` указывает на локальный `hosts.toml`, где у каждого псевдонима есть `hostname` и `port` — см. [шаблон](hosts.example.toml). Чтобы задать адрес прямо в параметрах плагина, укажите `config.env.DSH_SSH_HOST_ENDPOINTS` (JSON с `hostname` и необязательным `port` для уже существующих псевдонимов). Он не меняет пользователей, правила доступа и способ авторизации.
4. Сверьте ключ каждого хоста для фактического адреса и порта и внесите его в приватный `known_hosts`. Настройте авторизацию через Pageant с выбранным отпечатком и без fallback на пароль. Затем явно включите строку. Не публикуйте рабочие адреса, ссылки, ключи и результаты команд.

В репозитории нет данных действующей установки; фоновый legacy MCP Tasks поставляется отдельным bundle.
