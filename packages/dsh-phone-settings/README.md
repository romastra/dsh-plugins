# Доступ с телефона в настройках DSH

**Настройки → Доступ с телефона** — встроенная страница с актуальным QR, секретной ссылкой для входа, адресом выбранного адаптера, сведениями о сертификате и инструкциями. Отдельный HTML-файл открывать больше не нужно.

## Что доступно

- Все адаптеры Windows без фильтра: физические, виртуальные, VPN, туннели, скрытые, отключённые и без IPv4. У каждой записи видны имя, тип, состояние и адрес, если он есть; недоступные адаптеры можно сохранить для последующего подключения.
- Кнопка «Применить и запустить»: сохраняет GUID адаптера через штатный ConfigEditor DSH, закрывает предыдущий HTTPS-вход, выпускает сертификат для нового IPv4 и запускает порт **63819**. Корневой CA сохраняется.
- QR и копирование полной HTTPS-ссылки штатного авторизатора DSH.
- Сохранённый выбор, фактически активный адаптер/IP, порт 63819, состояние шлюза и срок серверного сертификата.
- Скачивание **открытого** корневого сертификата ЦС, его SHA-256 и срок действия.
- Установка сертификата на Android, вход через обычный Chrome, смена сети и устранение ошибок.

Данные обновляются при открытой странице. После смены IP нужен актуальный QR, но повторно устанавливать тот же корневой ЦС не требуется. Ссылка и QR дают полный доступ владельца — не пересылайте их другим.

## Безопасность

QR по умолчанию скрыт под размытой нейтральной заглушкой: настоящий QR вообще не рисуется до двойного клика. Повторный двойной клик скрывает его. Для клавиатуры предусмотрены два нажатия Enter/Пробела. При смене QR, уходе фокуса, скрытии окна или закрытии раздела маска восстанавливается; раскрытое состояние не сохраняется.

Для подключения страница читает несекретное состояние живого шлюза и его открытый сертификат. Переключение адаптера вызывает единую Host-операцию управления сетью. Токенизированную ссылку формирует штатный `connection.authenticatedUrl`, QR создаётся в памяти; исходный HTML и файлы QR не читаются. Приватные ключи, PFX и хранилище браузера не используются.

Данные и сертификат доступны через точные маршруты штатного авторизованного `/api`. Дополнительная проверка допускает только стандартного браузерного владельца DSH, а не независимые API Peer. Ответы не кешируются. Секретная ссылка не записывается в журнал, настройки, историю адресов или локальное хранилище страницы.

Скачивание сертификата и копирование ссылки — действия представления, не изменение конфигурации приложения и не выдача новых полномочий. Поэтому отдельный агентский инструмент для передачи секретного QR не добавляется.

## Выбор сети

Откройте **Настройки → Доступ с телефона**, выберите адаптер и нажмите **«Применить и запустить»**. Лучше делать это с компьютера: при смене IP прежнее подключение телефона прервётся. Затем установите открытый CA на телефон (один раз) и используйте актуальные ссылку и QR.

Показываются **все** адаптеры из объединённого инвентаря Windows, включая VirtualBox/Hyper-V, Tailscale/WireGuard/OpenVPN, программный loopback и отключённые интерфейсы. Нет фильтра по физическому типу, имени драйвера, частному диапазону IP, шлюзу по умолчанию или SkipAsSource. Публичные IPv4, адреса VPN, link-local 169.254.* и loopback 127.* допустимы. IPv6-only адаптер виден, но для этого IPv4-шлюза пока не имеет адреса запуска. Нулевой/широковещательный/многоадресный адрес не является адресом подключения, однако сам адаптер не скрывается.

Если на адаптере несколько IPv4, выбирается предпочтительный доступный адрес. Выбор привязан к GUID, а не к IP: изменения адресов отслеживаются автоматически. Отключённый адаптер или адаптер без IPv4 можно сохранить: шлюз будет ждать адреса, без ложного сообщения об успешном запуске. Если закреплённый адаптер исчезнет, вход закроется и **не переключится на другую сеть**.

Кнопка повторного запуска на том же адаптере позволяет восстановиться после сетевой ошибки или занятого порта. Сам по себе разрыв POST при перезапуске шлюза **не считается неудачным применением**: раздел повторно читает сохранённый GUID, активный GUID/IP и фазу шлюза. Подтверждённые совпадение и фаза ready дают сообщение об успехе; сохранённый выбор без адреса — сообщение об ожидании; ошибка запуска — её конкретную причину. Если текущую сеть уже нельзя опросить, результат честно остаётся неподтверждённым с предложением проверить его из окна компьютера. Новое успешное чтение снимает устаревшее сообщение о прерванном запросе. Сохранённый выбор не откатывается только из-за ошибки сети. Смена адаптера не отзывает штатный процессный токен DSH: секретный QR нельзя публиковать даже после переключения.

Управление использует существующий `@local/dsh-phone-secure`, не второй сервер. Для агентского управления той же операцией доступен инструмент `phone_network` (`list`, `select`), без передачи секретных ссылок и QR. POST требует штатного браузерного владельца, точного same-origin Origin и JSON; сторонние страницы не могут переключать сеть через CSRF.

Чтобы закрыть сетевой доступ, выключите набор **«Защищённый доступ с телефона»** в управлении плагинами. Выключение страницы настроек само по себе не останавливает шлюз. Локальный Desktop и его HTTP-loopback не перенастраиваются.

## Брандмауэр

Приложение открывает TCP-слушатель **только на выбранном локальном IP**, не на 0.0.0.0. Для маршрутизируемых VPN (включая локальный /32) адрес телефона не обязан попадать в префикс компьютера; каждый запрос по-прежнему требует штатную авторизацию DSH. Выбирая публичный IP, учитывайте, что порт может быть доступен и из маршрутизируемых внешних сетей; не передавайте секретный QR другим.

Настройки не меняют брандмауэр, не запрашивают повышение прав и не пробрасывают порты. Если Windows блокирует вход, проверьте правила для DSH и TCP 63819 на выбранной сети. Loopback доступен только с самого компьютера.

Поддерживается установленная DSH 0.2.2-rc.3. Client — готовый plain-JavaScript lazy-factory артефакт с React из таблицы модулей DSH; отдельная копия React, iframe, CDN и другой Web-сервер не нужны. Если раздел не появился после установки, обновите текущее окно приложения; полный перезапуск Host не требуется для самого этого набора, если менеджер не сообщает иное.

Значок — оригинальное изображение из нашего локального набора защищённого входа с телефона.

Для нового профиля сначала установите `@local/dsh-phone-secure` и явно включите его Host-строку. Оба пакета используют один каталог `phone-access` внутри DSH Home. Если переносите свой override `outputDir`, укажите одинаковое значение в обоих пакетах.
