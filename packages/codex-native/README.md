# Codex Native

Сборка для DSH Desktop **0.2.2-rc.5** с Pi AI **1.3.0**. OAuth, выбор Speed, ведение квот, восстановление replay и облачная компактация для Codex. Cloud по умолчанию включён только для новых обычных чатов и может быть выключен в чате.

Bundle поставляет код, но **не добавляет второй маршрут**. В вашей существующей Desktop-композиции оставьте прежний Host row с name `@local/codex-native` и его каталог состояния. В новом профиле см. [пример Host row](profile.example.yml): перед подключением убедитесь, что маршрут `openai-codex` не занят встроенным Pi AI или другим плагином. Затем войдите в Codex штатной кнопкой. Состояние и OAuth не переносятся через этот каталог. ACP имеет отдельный entry point и не включается автоматически.
