# Проверка происхождения контента / Content origin checker

Локальный плагин DeepSeek Harness. Добавляет агенту `content_origin_check` и `content_origin_info`. Установлен в профиль через Plugin Manager; действует во всех его сессиях и сохраняется после перезапуска. Не создаёт отдельную страницу.

## Что проверяется

- **Изображения:** официальный SDK `contentauth/c2pa-python` проверяет встроенные Content Credentials, подпись, привязку к содержимому и доверие к подписанту. Заявления `digitalSourceType` об ИИ в поддерживаемых действиях `c2pa.actions` / `c2pa.actions.v2` активного манифеста отделены от результата валидации. Произвольные custom assertions и ссылки на ингредиенты не считаются декларацией происхождения текущего файла. Неподписанные EXIF/PNG/XMP-подсказки выделены отдельно. Локальный ViT-классификатор даёт только слабый статистический сигнал.
- **Русский текст:** локальный ONNX-классификатор `toiletsandpaper/russian-ai-text-detector-bert`, обученный на русской части LLMTrace. Поддерживаются минимум 80 слов и только начало текста (510 нормализованных токенов). Более длинный хвост явно помечается непроверенным. Для короткого текста и других языков — отказ от оценки.
- **SynthID:** НЕ декодируется. Поле `synthid.status` всегда `not_checked`. Упоминание в метаданных не подтверждает водяной знак в пикселях. Открытый SynthID Text требует подходящих ключей, токенизатора и настроек генерации; публичный пример не проверяет произвольные тексты Gemini.

## Как пользоваться

Просто попросите агента «Проверь этот текст/изображение на ИИ» и передайте текст или исходный локальный файл. Инструмент также принимает структурированную ссылку DSH на изображение. Для проверки подписи предпочтителен **оригинальный файл**: нормализация картинки при загрузке в чат может удалить метаданные, подпись или водяной знак.

Результат содержит отдельные блоки `c2pa`, `metadata`, `classifier`, `synthid`, предупреждения и SHA-256 проверенных байтов. Отсутствие признаков никогда не выдаётся за «создано человеком». Даже доверенная C2PA-подпись удостоверяет декларацию подписанта и целостность, а не правдивость изображённой сцены.

## Ограничения точности

Это не универсальная экспертиза и не средство принятия решений о людях. Число `score` — выход классификатора, **не калиброванная вероятность авторства**. Автор русской модели сообщает 7,2% ложных срабатываний на человеческих текстах при пороге 0,5 на своём test. Автор модели изображений сообщает лишь около 72% точности на своей real-world выборке. Эти метрики нами не воспроизведены, на новых моделях и других жанрах они могут быть хуже. Классификатор изображений обучен в основном на более старых Midjourney / Stable Diffusion. Компрессия, скриншоты, рисунки, генераторы 2026 года и смешанная редактура не покрываются гарантией.

Пределы: 32 MiB/файл, 25 мегапикселей, 200 000 символов текста, 2 параллельных проверки. GIF/TIFF с несколькими кадрами не получают единого пиксельного вердикта. Ошибки парсинга C2PA не маскируются под отсутствие подписи. Проверяются только встроенные credentials; удалённые манифесты не скачиваются.

## Приватность и воспроизводимость

Worker не загружает проверяемые файлы/тексты внешним сервисам детекции. Это **не полностью автономный режим DSH**: текст, вставленный в чат или аргументы инструмента, уже доступен выбранному LLM-провайдеру и журналу DSH; отчёт инструмента (метаданные, подписант, локальный путь, SHA-256, оценки) также передаётся агенту и может попасть облачному LLM-провайдеру. Для конфиденциальной проверки используйте локальный LLM и исходный локальный файл вместо вставки содержимого в чат. Worker не принимает URL или команды, работает в отдельном краткоживущем процессе, получает только JSON и байты от штатного FS/Attachments DSH. Сетевые пути SDK (remote manifests, OCSP, декодирование CAWG identity) выключены; внешние hosts не разрешены, телеметрия ONNX отключена. CAWG-идентичности не проверяются. Исходное содержимое локального текстового файла worker обратно не копирует; небольшие выдержки метаданных могут входить в отчёт как недоверенные данные.

Модели закреплены commit SHA и проверяются по SHA-256 перед загрузкой. Код моделей с Hugging Face не выполняется (`trust_remote_code` не используется). Python-зависимости находятся в изолированном `.venv`, системный Python не меняется. `requirements.txt` фиксирует прямые зависимости, `requirements.lock.txt` — фактически установленные транзитивные версии.

Данные C2PA Conformance + TSA и Interim Trust List скачаны отдельно с официальных репозиториев. Для подписанта используется явно обозначенная смешанная локальная политика `local_conformance_plus_legacy_interim_v1`: Conformance roots + замороженные legacy roots/leaf allow-list CAI; trust по этой политике **не означает сертификацию C2PA Conformance**. Совпавший конкретный anchor не определяется. Timestamp-only корни не добавляются в signer anchors; из-за этого некоторые timestamps могут остаться недоверенными. Дата, commit SHA и хеши — в `trust/snapshot.json`. Во время проверки сети нет, свежие отозванные сертификаты могут не учитываться. Через 30 дней snapshot помечается устаревшим и не позволяет выдать `trusted_under_snapshot_policy`. Обновление доверия — явный запуск `setup_assets.py` после проверки изменений, не фоновая задача.

## Установка и разработка

В репозитории нет venv, весов и старых списков доверия. Установите bundle из Discover. Чтобы подготовить runtime, из клона перейдите в `packages/content-origin` и выберите каталог данных `<data-dir>` — по умолчанию `content-origin` внутри DSH Home. Запустите `python -m venv "<data-dir>/.venv"`, а затем Python из этого venv с `-m pip install --only-binary=:all: -r requirements.lock.txt`. Выполните `python setup_assets.py --data-dir "<абсолютный data-dir>"`: установка использует закреплённые SHA-256 моделей и свежий публичный trust snapshot. Не размещайте данные в пакете. Проверьте `content_origin_info` в DSH.

Для этой машины пакетам перед установкой проверены SHA-256 wheel из PyPI JSON; локальный реестр — `wheels.lock.json`. При разработке добавлено два инструмента и короткая секция поведения: 2286 UTF-8 bytes в схемах и тексте (примерно 572 токена; точная токенизация зависит от модели, до установки плагин добавлял 0). Лицензии и источники — `THIRD_PARTY.md`. Иконка оригинальная, создана для этого плагина (MIT).
