# Глубина рассуждений / Reasoning depth

Установленный плагин добавляет компактный голубой ползунок сразу под полем ввода, перед статистикой. Акцент — голубой `--dsw-alias-state-business-primary`, как у основных действий Harness; контейнер и бегунок используют цвета активной темы. Обёртка dock с этим ползунком разрешает перенос строк: ползунок занимает всю первую строку, существующая статистика и индикатор контекста остаются ниже.

- Одна точка на каждый доступный вариант текущей модели; порядок и названия берутся из каталога адаптера. Синтетической ступени Default/Авто больше нет. Если адаптер не сообщает именованный default и явный effort не задан, показано «Выберите уровень» без выбранной точки; ничего автоматически не записывается. None показывается только если адаптер действительно предлагает такой режим.
- Перетаскивание показывает предварительный выбор; запись происходит при отпускании. Доступны щелчок по шкале, касание, стрелки, Home и End. Escape отменяет незавершённый выбор.
- Правая область заранее резервирует ширину самого длинного названия среди всех доступных уровней модели через невидимую CSS-grid ячейку. Переключение Max / Extra High и перетаскивание не меняют ширину шкалы; скрытые названия исключены из дерева доступности. На узких экранах резерв ограничен, слишком длинный текст сокращается с подсказкой.
- Штатное меню и ползунок используют один `modelDirectories` / `ModelDirectory` и `sessionController.selectModel`. Нет второго хранилища или перехвата запроса модели. Как и штатное меню, выбор также сохраняет модель/глубину по умолчанию для сеансов без собственного явного выбора. Уже начатый шаг не меняется; настройка применяется к следующему запросу.
- Без доступных уровней или в адресованном дочернем сеансе ползунок скрыт. При отсутствии права `session/selectModel` показан read-only. Во время записи повторный выбор блокируется, ошибка отображается в панели.
- Высота компактной панели — 28 CSS px вместо 56; видимая шкала — 9,33 px вместо 14 (тоньше в 1,5 раза). На узкой панели остаётся иконка с доступной подписью, шкала не переносится на вторую строку. Нативный input[type=range] сохраняет клавиатуру и скринридеры; на сенсорном экране область захвата увеличена без роста панели.
- Точки шкалы — непрозрачные белые (4 px); бегунок с белой заливкой и голубым контуром. Белый цвет намеренно не затемняется активной тёмной темой.
- До первого сообщения ползунок добавляется через отдельный элемент `conversation.input.dock` и располагается после карточки ввода в потоке Hero. Использует тот же сеанс и ModelDirectory, что штатный селектор, не создаёт фиктивный диалог. При появлении обычного нижнего dock стартовый экземпляр скрывается, после выхода из blank — размонтируется.
- UI локализован на русском, английском и китайском; название и описание в каталоге снабжены оригинальной SVG-иконкой (MIT).

## Agent operation

`reasoning_depth` с `action: get` возвращает выбранную модель и доступные effort id. `action: set` принимает такой id в `effort`; отсутствие effort включает default адаптера. Оба вызывающих используют существующий Host `sessionController.selectModel` и не меняют модель. Инструмент работает только со своим текущим сеансом.

## Скругление панели цели

Ongoing Goal использует тот же `--dsw-radius-lg`, что и штатная панель To-dos. Точечный стиль `[data-goal-bar] > div` меняет только радиус контейнера, в том числе при редактировании цели; размеры, кнопки и логика цели не меняются. Фоновый псевдоэлемент наследует этот радиус. Стиль зарегистрирован отдельным невидимым элементом в `conversation.input.dock` и удаляется при отключении плагина.

## Development

`node build.mjs` собирает самостоятельный Client-артефакт из исходников без внешних библиотек, кроме React от Harness. `node --test test/*.test.mjs` проверяет чистую логику выбора и Host-адаптер. Плагин установлен локальной ссылкой на этот каталог: не удаляйте его, пока используете плагин.

## Переключение во время работы

Ползунок не блокируется от `session.running` и не вызывает Stop, cancel или restart. Живой тест в текущем работающем сеансе переключил Max → Extra High → Max без остановки. Уже подготовленный/идущий запрос сохраняет свой уровень, следующий шаг, включая продолжение после инструмента в том же ходе, берёт новую настройку.

Ползунок меняет только effort при том же provider/model, не очищает историю и не переписывает replay. В установленном `dsh-plugin-subscriptions` 0.9.12 для Codex обнаружено отдельное ограничение: запрошенный `reasoning.encrypted_content` не сохраняется и не переотправляется между обычными запросами. Поэтому непрерывность скрытых рассуждений не гарантируется даже без ползунка. По просьбе пользователя адаптер оставлен без изменений.

## Verification scope

Синтаксис JavaScript, локальные тесты, ресурсы пакета и live-регистрация слота проверяются при установке. Если в текущей среде нет браузерного управления, итоговая отрисовка и реальные pointer/keyboard-жесты требуют проверки пользователем в подключённом интерфейсе; успешная регистрация сама по себе не подтверждает визуальное соответствие.
